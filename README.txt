VS Chem Dispatch App - วิธีขึ้น GitHub Pages
1) อัปโหลดทุกไฟล์ในโฟลเดอร์นี้ (index.html, manifest.webmanifest, sw.js, โฟลเดอร์ icons) ไปไว้ที่ราก repo เดียวกัน
2) Settings > Pages > เลือก branch main / root
3) เปิดลิงก์ https://<ชื่อ>.github.io/<repo>/ ด้วย HTTPS
   - Android (Chrome): เมนู ⋮ > ติดตั้งแอป / Add to Home screen
   - iPhone (Safari): ปุ่มแชร์ > Add to Home Screen
   - คอมพิวเตอร์ (Chrome/Edge): ไอคอนติดตั้งที่ช่อง URL
4) Code.gs ใช้ติดตั้งกับ Google Sheet (ดูขั้นตอนในแชท)
